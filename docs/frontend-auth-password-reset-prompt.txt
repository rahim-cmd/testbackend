You are building authentication UI for this backend. Implement Change Password and Forgot/Reset Password flows using the APIs below.

Base URL
- http://localhost:5000/api/v1/auth

1) Change Password (Logged-in User)
Endpoint
- POST /change-password
Headers
- Authorization: Bearer <access_token>
- Content-Type: application/json
Body
{
  "current_password": "OldPass@123",
  "new_password": "NewPass@123"
}
Success Response (200)
{
  "success": true,
  "message": "Password changed successfully."
}
Validation/Error Response (400/422)
{
  "success": false,
  "message": "Current password is incorrect."
}

Frontend behavior
- Form fields: current password, new password, confirm new password.
- Client-side checks: min length 8, new/confirm must match.
- On success: show success toast and force user re-login (recommended).

2) Forgot Password (Registered User)
Endpoint
- POST /forgot-password
Headers
- Content-Type: application/json
Body
{
  "email": "user@example.com"
}
Success Response (always generic)
{
  "success": true,
  "message": "If this email is registered, a password reset link has been sent."
}

Frontend behavior
- Form field: email.
- Always show same success message to prevent email enumeration.
- After submit, show instruction: "Please check your email inbox/spam."

3) Reset Password (From Email Link)
Endpoint
- POST /reset-password
Headers
- Content-Type: application/json
Body
{
  "token": "<token-from-email-link>",
  "new_password": "NewPass@123",
  "otp": "123456"
}
Notes
- otp is optional. Token is required.
- Token expiry is controlled by backend env PASSWORD_RESET_EXPIRES_MINUTES (default 15).

Success Response (200)
{
  "success": true,
  "message": "Password reset successful."
}
Error Response (400)
{
  "success": false,
  "message": "Invalid or expired reset token."
}

Frontend route suggestion
- /forgot-password
- /reset-password?token=<token>

Reset page behavior
- Read token from query param.
- Form fields: new password, confirm password, optional otp.
- On submit success: navigate to login page and show success message.

Suggested React service helpers
- changePassword(payload, token)
- forgotPassword(email)
- resetPassword(payload)

Example fetch snippets

Change Password:
fetch('/api/v1/auth/change-password', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${token}`
  },
  body: JSON.stringify({
    current_password,
    new_password
  })
})

Forgot Password:
fetch('/api/v1/auth/forgot-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email })
})

Reset Password:
fetch('/api/v1/auth/reset-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ token, new_password, otp })
})

UX/security checklist
- Never reveal whether email exists.
- Disable submit button while request is pending.
- Handle 422 validation errors per-field.
- Clear password fields on success and on page leave.
- Add password visibility toggles for usability.
